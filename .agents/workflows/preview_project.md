# Preview Project Workflow

This workflow details the commands required to start a local development server to preview, interact with, and test the web application.

## Steps

### 1. Start the Dev Server
Launch the Next.js dev server:
```bash
npm run dev
```

### 2. Verify Server is Running
The server will start, by default on `http://localhost:3000`. 
Verify the output log shows:
```text
▲ Next.js 15.5.9
- Local:        http://localhost:3000
- Environments: .env
```

### 3. Open Preview
Access the application by opening the URL in a browser:
- Main Page: `http://localhost:3000/`
- Cantor Cloud: `http://localhost:3000/cantor-cloud`
- Debug Page: `http://localhost:3000/debug`
