# **App Name**: Hymn Tutor

## Core Features:

- Hymn Genre Selection: Display a list of hymn genres (Holy Week, Kiahk, Resurrection) on the home screen for easy selection.
- Hymn Roster: List available hymns within each genre (e.g., Tai shouri, Agios, Omonogenees for Holy Week).
- Track Selection: Allow users to select from multiple recordings of each hymn (Cantor Tharwat, Cantor Ibrahim, Cantor Gad) with a default option.
- Playback Controls: Provide standard play/pause buttons with additional controls for repeat, next, and previous section navigation.
- Speed Adjustment: Implement playback speed control, ranging from 1.0x to 2.0x in 0.1x increments.
- Section Looping: When enabled, continuously loop playback of the selected section between two marks.
- Track Navigation: Allow user to seek to any second of the track. User can define 'marks' at a given point on the track in the minute/second, and enable or disable them, meaning the section should consider the mark for snapping to the next position.

## Style Guidelines:

- Primary color: Deep Indigo (#4B0082) to evoke a sense of reverence and tradition.
- Background color: Light Lavender (#E6E6FA) for a soft and calming backdrop.
- Accent color: Gold (#FFD700) to highlight key interactive elements with a touch of elegance.
- Body and headline font: 'Alegreya', a humanist serif with an elegant, intellectual, contemporary feel, for both headlines and body text.
- Use simple, elegant icons to represent genres and playback controls, in a style reminiscent of Coptic art.
- Maintain a clean and structured layout with clear hierarchy to ensure ease of navigation and focus on the hymn tracks.
- Employ subtle transitions and animations for a smooth and engaging user experience when navigating and playing tracks.
